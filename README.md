# movie-town
Movie list website using ReactJs, Html, Css, Javascript


# Start Project
Create a .env file with the following variables and their values
Example:
REACT_APP_API_KEY=API_KEY

To get the API_KEY for your application go to [tmdb](https://www.themoviedb.org/settings/api)
